## 🎨 Design Highlights

- **Neo-Brutalist UI** — thick borders, offset shadows, high-contrast palettes
- **Paper Tear Effect** — SVG torn edges that close on scroll with parallax + tape sticker
- **Matrix Typing Effect** — hero greeting scrambles through random characters before resolving
- **Scroll-Driven Highlights** — text highlights animate in like a highlighter pen
- **Interactive Map** — Leaflet.js journey map with pirate theme and grid overlay
- **Falling Decorative Icons** — SVG icons drop with gravity on scroll
- **Dark Mode** — full light/dark theming via CSS custom properties

### Color System

| Color | Variable | Usage |
|-------|----------|-------|
| Yellow | `--yellow` | Primary accent, CTAs, loader |
| Cyan | `--cyan` | Code elements, highlights |
| Pink | `--pink` | Secondary accent, highlights |
| Green | `--green` | Success states, highlights |
| Black | `--border` | Borders, shadows, text |
